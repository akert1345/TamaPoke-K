# TamaPoke 3.110.10

Waveshare ESP32-S3 Touch AMOLED 1.75, 466×466, 16 MB Flash, OPI PSRAM용입니다. 3.110.6 배틀 타워 수정본에 성장 및 난이도 조정을 적용했습니다.

## 새 GitHub 저장소

ZIP을 풀고 파일을 저장소 루트에 올립니다. 숨김 폴더인 `.github`도 포함해야 합니다. 저장소 Settings → Pages → Source에서 GitHub Actions를 선택하고, Actions → TamaPoke ESP32-S3 Pages → Run workflow를 실행합니다. 배포가 끝나면 실행 결과에서 설치 페이지 주소를 확인할 수 있습니다.

기존 TamaPoke와 동일한 파티션을 쓰는 기기용 앱 업데이트로 구성했습니다. 설치 시 플래시 삭제 옵션은 해제하세요. microSD에 이미 설치한 파일은 그대로 사용합니다. 기존에 받은 리소스 ZIP이 있다면 별도로 보관하세요.

펌웨어의 리소스 헤더, 종 ID와 로딩 경로는 그대로입니다. Pages 워크플로는 리소스를 다시 생성하거나 새 팩을 기기로 전송하지 않습니다.

## 성장과 대전

레벨당 2 XP입니다. 자동 성장만으로는 깨어 있을 때 약 20분, 펫이 잠들었을 때 약 100분에 한 레벨이 오릅니다. 저장된 레벨과 현재 진행도는 기존 단위를 사용합니다.

| 활동 | XP |
|---|---:|
| 훈련 4종 | 성과에 따라 0~2 |
| 야생 승리 | 1 |
| 타워·라이벌 승리 | 4 |
| 타입 보스 승리 | 6 |
| 첫 체육관 배지 | 일반 6 / 하드 8 |
| 배지 획득 뒤 체육관 재승리 | 2 |

대전 XP는 출전 명단에 포함된 활성 육성 슬롯이 받습니다. 체육관 일반·하드 모두 상대 AI가 기술을 판단하며, 모든 상대의 HP/전투 능력치를 각각 일반 +20%/+15%, 하드 +45%/+32% 올렸습니다. 타워와 라이벌도 첫 전투부터 판단형 AI를 사용합니다. 타워는 기본 상대 레벨이 3 높고 연승마다 1씩 오르며, 라이벌과 타입 보스도 상대 능력치와 체력을 높였습니다.

## DMUL Dragon 확장

- 불꽃·얼음 계열은 기존 DMUL Dragon 알에서 시작합니다. 기기몬이 민첩(SPE) 훈련 우세일 때 보보몬, 도리몬이 체력(HP) 훈련 우세일 때 블루코몬으로 진화합니다.
- 성장기 이후 각 계열은 Lv.12, 25, 45에 차례로 진화합니다. 다음 단계는 계열별로 고정됩니다.
- 기존 0–457 ID는 그대로이며 확장 16종은 458–473입니다. 3.110.10 펌웨어와 해당 microSD 팩을 함께 적용하세요.
- Pages의 SD 팩 링크 또는 로컬 `site/dmul-sd-pack.html`을 PC 브라우저에서 열어 ZIP을 만듭니다. 압축을 풀고 `digimon` 폴더를 microSD 최상위에 병합하세요.

- 무기 계열은 DMUL Dragon 기기몬의 체력(HP) 우세에서 즈바몬으로 시작합니다. 드라코몬은 기존 방어(DEF) 경로로 진화할 수 있습니다.
- DMUL Dark 츠메몬의 방어(DEF) 우세는 드라크몬으로 진화합니다. 야생 벰몬에게 승리하거나 벰몬 육성 기록이 있으면, 츠메몬의 상태 카드에서 일반 진화를 눌러 벰몬을 선택할 수 있습니다.
- 새 두 계열도 Lv.12, 25, 45에 다음 단계로 진화합니다. 앞선 8종을 이미 설치했다면 생성기에서 ‘추가 8종만’을 선택하세요.
- 생성기의 미리보기는 게임이 읽는 DGI3 동작 슬롯과 같은 원본 PNG를 보여줍니다. 공격은 준비 자세에서 원본 공격 자세로 전환합니다.

화면은 미입력 90초 뒤 어두워지고 3분 뒤 꺼집니다. 배터리 구동 중 화면이 꺼지면 USB·무선·활성 전투·훈련·저장 여부를 확인한 뒤 타이머 기반 Light Sleep을 시도합니다. 측면 버튼과 육성 처리를 위해 300ms 간격으로 CPU를 깨웁니다. 수면 API가 실패하면 해당 부팅 동안 일반 화면 꺼짐으로 복귀합니다.
