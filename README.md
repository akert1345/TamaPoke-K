# TamaPoke 3.110.7

Waveshare ESP32-S3 Touch AMOLED 1.75, 466×466, 16 MB Flash, OPI PSRAM용입니다. 3.110.6 배틀 타워 수정본에 성장 및 난이도 조정을 적용했습니다.

## 새 GitHub 저장소

ZIP을 풀고 파일을 저장소 루트에 올립니다. 숨김 폴더인 `.github`도 포함해야 합니다. 저장소 Settings → Pages → Source에서 GitHub Actions를 선택하고, Actions → TamaPoke ESP32-S3 Pages → Run workflow를 실행합니다. 배포가 끝나면 실행 결과에서 설치 페이지 주소를 확인할 수 있습니다.

기존 TamaPoke와 동일한 파티션을 쓰는 기기용 앱 업데이트로 구성했습니다. 설치 시 플래시 삭제 옵션은 해제하세요. microSD에 이미 설치한 파일은 그대로 사용합니다. 기존에 받은 리소스 ZIP이 있다면 별도로 보관하세요.

펌웨어의 리소스 헤더, 종 ID와 로딩 경로는 그대로입니다. Pages 워크플로는 리소스를 다시 생성하거나 새 팩을 기기로 전송하지 않습니다.

## 성장과 대전

레벨당 2 XP입니다. 자동 성장만으로는 깨어 있을 때 약 20분, 펫이 잠들었을 때 약 100분에 한 레벨이 오릅니다. 저장된 레벨과 현재 진행도는 기존 단위를 사용합니다.

| 활동 | XP |
|---|---:|
| 훈련 4종 | 성과에 따라 0~2 |
| 야생 승리 | 1 |
| 타워·라이벌 승리 | 4 |
| 타입 보스 승리 | 6 |
| 첫 체육관 배지 | 일반 6 / 하드 8 |
| 배지 획득 뒤 체육관 재승리 | 2 |

대전 XP는 출전 명단에 포함된 활성 육성 슬롯이 받습니다. 체육관 일반·하드 모두 상대 AI가 기술을 판단하며, 모든 상대의 HP/전투 능력치를 각각 일반 +20%/+15%, 하드 +45%/+32% 올렸습니다. 타워와 라이벌도 첫 전투부터 판단형 AI를 사용합니다. 타워는 기본 상대 레벨이 3 높고 연승마다 1씩 오르며, 라이벌과 타입 보스도 상대 능력치와 체력을 높였습니다.
